# ResumeCraft

ResumeCraft is a simple and user-friendly resume building project designed to help users create and manage a professional resume.

## Features

* Simple and clean user interface
* Easy resume creation
* Responsive design
* User-friendly layout
* HTML, CSS and JavaScript based project

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Purpose

The main purpose of ResumeCraft is to provide an easy way for users to create a structured and professional-looking resume.
